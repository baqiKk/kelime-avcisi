# Kelime Avcısı

5 harfli Türkçe kelime oyunları (Wordle benzeri, günlük konulu) için yardımcı araç.

## Özellikler
- Wordle görünümlü tahta: harflere tıklayarak gri / turuncu / yeşil ayarla
- ~5.600 kelimelik 5 harfli Türkçe sözlükle anlık filtreleme
- Günün konusu: konu kelimeleri öne çıkar, tahmin önerisi onlara göre hesaplanır
- Sıradaki en iyi tahmin: kalan adayları en çok daraltan kelimeyi önerir
- Kendi konunu oluştur: herhangi bir yapay zekaya yapıştırılacak hazır komut

## Kullanım
Tek dosya, sunucu gerekmez. `index.html` dosyasını tarayıcıda açman yeterli.
